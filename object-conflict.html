PACT problem types, revision -01

object-conflict

https://pact-spec.github.io/problem/object-conflict

HTTP status
409
Defined by
The reference implementation. Revision -01 does not list it.
Section named
Section 12.2 of revision -01

When it is returned

The object conflicts with one the Facilitator already holds. There are four cases: a contract posted under an identifier that already holds a different contract; a Delivery whose vtc_hash does not commit to the contract; and a Verdict or a Challenge whose delivery_hash does not commit to the recorded Delivery.

The response names Section 12.2, the section on idempotency, in all four cases. Only the first is a rule of that section. In the last three the response also carries the digest the Facilitator expected and the one it received.

Recorded examples

  • Event 36 of the recorded run, status 409: “contract r_idem exists with a different digest”
  • Test vector reject/03-verdict-delivery-hash-unsigned, status 409: “delivery_hash does not commit to the recorded Delivery”
  • Test vector reject/04-delivery-vtc-hash-unsigned, status 409: “vtc_hash does not commit to this contract”
  • Test vector reject/05-delivery-vtc-hash-number-form, status 409: “vtc_hash does not commit to this contract”

These identifiers belong to revision -01 of draft-laxsharma-pact, an individual Internet-Draft that later revisions have superseded. Later revisions do not use this prefix.

The implementation described is the reference implementation at tag v0.1.2 of pact-spec/spec.
